Statistische Tests und Vertrauensintervalle

Ist ein Sollwert mit den Daten verträglich? Ein Test entscheidet das rezeptartig: Hypothesen, Niveau α, Verwerfungsbereich, Entscheidung. Dazu Fehler 1. und 2. Art, Macht, P-Wert (Signifikanz), die Dualität zum Vertrauensintervall und die verteilungsfreien Vorzeichen- und Wilcoxon-Tests.

📘 Grundlage🔗 Roter Faden: Modell und Hypothesen aufstellen → Niveau α wählen → Verwerfungsbereich K unter H₀ bilden → prüfen, ob die Teststatistik in K fällt. Der P-Wert fasst das in einer Zahl zusammen; das Vertrauensintervall ist die Menge aller nicht verworfenen Sollwerte.

7.0Master-Anatomie

✚ Neu🔬 Anatomie: jeder Test in einer Zeile
\[ \underbrace{\Cond{H_0}:\theta=\Par{\theta_0}}_{\text{Status quo}}\ \text{vs.}\ \underbrace{\Cond{H_A}}_{\text{Vermutung}}\ \xrightarrow{\ \Par{\alpha}\ }\ \Res{K}\ \text{mit}\ \PP_{H_0}(\text{Statistik}\in K)\le\Par{\alpha}\ \xrightarrow{\text{Daten}}\ \text{Statistik}\in\Res{K}\ ? \]
\(H_0\)Nullhypothese: der Sollwert, den wir anzweifeln
\(H_A\)Alternative: was wir nachweisen wollen; bestimmt die Form von K
\(\alpha\)Niveau: maximale W'keit, H₀ fälschlich zu verwerfen
\(K\)Verwerfungsbereich, vor dem Blick auf die Daten unter H₀ konstruiert
📖 Vorlesen: „Wir legen H null und die Alternative fest, wählen alpha, bauen K unter H null und verwerfen, wenn die Statistik in K liegt.“
📘 Grundlage🎓 Das agnostische Spitzenwerkzeug für JEDE Testfrage
  1. ERKENNEN: Daten und ein Sollwert (\(\mu_0\), \(p_0\)). Ist die Abweichung signifikant (Test)? Welche Werte sind plausibel (VI)?
  2. WÄHLEN: Bin → Binomialtest · Normal, σ bekannt → Z-Test · Normal, σ unbekannt → t-Test · nicht normal → Vorzeichen-/Wilcoxon-Test. Alternative ein-/zweiseitig. Niveau α (meist 0.05).
  3. RECHNEN: Teststatistik bilden, Verwerfungsbereich aus den Quantilen, prüfen ob Statistik ∈ K, oder P-Wert mit α vergleichen.
  4. ARTIKULIEREN: „Die Teststatistik ist […]; sie liegt (nicht) in K / der P-Wert ist […] < α. Also verwerfen wir H₀ und haben H_A statistisch nachgewiesen / können H₀ nicht verwerfen.“
📘 Grundlage🧭 Die 7 Leitfragen dieses Kapitels
  1. Was will ein Test entscheiden? Ob ein Sollwert mit den Daten verträglich ist.
  2. H₀ und H_A? Status quo vs. was wir zeigen wollen.
  3. Fehler 1. und 2. Art? H₀ fälschlich verwerfen vs. fälschlich beibehalten.
  4. Niveau α? Kontrolliert die W'keit für einen Fehler 1. Art.
  5. Wie entscheidet man? Teststatistik in K → verwerfen.
  6. P-Wert? Das kleinste α, bei dem man gerade noch verwirft.
  7. Vertrauensintervall? Die Menge aller nicht verworfenen H₀, dual zum Test.

7.1Die Konzepte am Binomialtest

✚ Neu
Von null · Abschnitt 7.1Hält der Lieferant seine 5-%-Zusage ein?
Prüfungsaufgabe (für sich allein lösbar). Ein Lieferant garantiert höchstens 5 % Ausschuss. In einer Stichprobe von n = 50 Teilen sind x = 6 defekt. Teste zum Niveau α = 0.05, ob der Ausschussanteil größer als 5 % ist: (a) Modell und Hypothesen, (b) Verwerfungsbereich K, (c) Entscheidung und P-Wert, (d) was wäre ein Fehler 1. und 2. Art?
Lösung von null, Schritt für Schritt
1
(a) Modell und Hypothesen. \(\Mem{X}\) = Anzahl defekt \(\sim\Bin(50,p)\). \(\Cond{H_0}:p=\Par{0.05}\) (Zusage stimmt), \(\Cond{H_A}:p>0.05\) (wir vermuten mehr).
2
(b) K nach oben, kleinstes c mit P(X ≥ c) ≤ α. \[\begin{aligned} \PP_{p_0}(X\ge5) &= 0.1036 && > 0.05\ \text{zu groß} \\ \PP_{p_0}(X\ge6) &= 0.0378 && \le 0.05\ \text{passt} \\ \Res{K} &= \{6,7,\dots,50\} && \text{Form wie }H_A\text{ (nach oben)} \end{aligned}\]
3
(c) Entscheidung. \(x=6\in K\) → H₀ verwerfen. P-Wert \(=\PP_{p_0}(X\ge6)=\Res{0.0378}\le0.05\).
4
(d) Fehlerarten. Fehler 1. Art: wir werfen dem Lieferanten zu Unrecht mehr Ausschuss vor (W'keit ≤ 0.05, hier 0.0378). Fehler 2. Art: er liefert tatsächlich mehr, aber unser Test bemerkt es nicht.
✔ K = {6, …, 50}; x = 6 ∈ K → H₀ verworfen, P-Wert ≈ 0.038. „Der Ausschussanteil ist statistisch signifikant größer als 5 %.“
⚠ Typische Falle. Das tatsächliche Niveau (0.0378) ist bei diskreten Tests meist kleiner als α; man kann α nicht exakt ausschöpfen.

Beispiel: Ein Hersteller sagt, höchstens 10 % der Bauteile sind Ausschuss (\(p_0=0.1\)). Wir vermuten, es sind mehr. Ist unsere Beobachtung mit seiner Behauptung verträglich?

\(\alpha\)Signifikanzniveau: erlaubte Obergrenze für einen Fehler 1. Art (meist 0.05 oder 0.01)
📖 Vorlesen: „Die W'keit, unter H null im Verwerfungsbereich zu landen, ist höchstens alpha.“
📘 Grundlage💡 Merke: Man wählt das kleinste c, sodass \(\PP_{p_0}(X\ge c)\le\alpha\). Der Verwerfungsbereich K hat immer dieselbe „Form“ wie die Alternative (nach oben / unten / beidseitig).
📘 Grundlage
🎓 Prüfungs-Trainer. Ein Test verwirft H₀, obwohl H₀ stimmt. Wie heißt dieser Fehler, und welche Größe steuert seine W'keit?

🗣️ SAGEN„Das ist ein Fehler erster Art; seine W'keit wird durch alpha kontrolliert.“

Code: den Verwerfungsbereich suchen

R · BinomialtestBasis-R, vollständig lauffähig
1# Binomialtest einseitig nach oben: Verwerfungsbereich K = {g, ..., n} konstruieren
2n <- 50; p0 <- 0.05; alpha <- 0.05; x <- 6   # H0: p = p0, HA: p > p0, Beobachtung x
3g <- 0                                     # Kandidat g für die Grenze von K
4repeat {                                   # kleinstes g mit P(X >= g) <= alpha suchen
5  schwanz <- 1 - pbinom(g - 1, n, p0)      # P_{p0}(X >= g), W'keit für Fehler 1. Art
6  if (schwanz <= alpha) break              # klein genug: gefunden
7  g <- g + 1                               # sonst Grenze nach rechts schieben
8}
9pwert <- 1 - pbinom(x - 1, n, p0)          # P-Wert: P(X >= x) unter H0
10cat("K = {", g, ",...,", n, "}  x in K:", x >= g, " p =", pwert, "\n")
11binom.test(x, n, p0, alternative = "greater")   # eingebaut
Python · Binomialtestnumpy / scipy / matplotlib, vollständig lauffähig
1# Binomialtest einseitig nach oben: Verwerfungsbereich K = {g, ..., n} konstruieren
2from scipy import stats
3
4n, p0, alpha, x = 50, 0.05, 0.05, 6        # H0: p = p0, HA: p > p0, Beobachtung x
5g = 0                                      # Kandidat g für die Grenze von K
6while True:                                # kleinstes g mit P(X >= g) <= alpha suchen
7    schwanz = stats.binom.sf(g - 1, n, p0) # P_{p0}(X >= g), W'keit für Fehler 1. Art

7.2Tests bei normalverteilten Daten: Z-Test und t-Test

✚ Neu
Von null · Abschnitt 7.2t-Test aus acht Messwerten, komplett von Hand
Prüfungsaufgabe (für sich allein lösbar). Acht Messungen einer Konzentration: 5.1, 4.9, 5.6, 5.8, 5.3, 5.5, 5.2, 5.4. Weicht der Erwartungswert vom Sollwert \(\mu_0=5\) ab? Teste zweiseitig mit α = 0.05 (Normalverteilung angenommen, σ unbekannt).
Lösung von null, Schritt für Schritt
1
Welcher Test? Normal, σ unbekannt → t-Test mit \(n-1=7\) Freiheitsgraden. \(H_0:\mu=5\), \(H_A:\mu\ne5\).
2
Kennzahlen. \(\bar x=\tfrac{42.8}{8}=5.35\); \(s=0.2878\) (Nenner 7); \(\operatorname{SE}=s/\sqrt8=0.1018\).
3
Teststatistik. \[\begin{aligned} \Res{t} &= \frac{\bar x-\mu_0}{s/\sqrt n}=\frac{5.35-5}{0.1018} && \text{Abweichung in Standardfehlern} \\ &\approx \Res{3.44} && \text{ausgerechnet} \end{aligned}\]
4
Verwerfungsbereich. \(t_{7,\,0.975}=2.365\) → \(K=(-\infty,-2.365]\cup[2.365,\infty)\).
5
Entscheidung. \(|3.44|\ge2.365\) → H₀ verwerfen. P-Wert \(=2\,\PP(T_7\ge3.44)\approx\Res{0.011}\).
✔ t ≈ 3.44 > 2.365, P ≈ 0.011: der Erwartungswert weicht signifikant von 5 ab. R: t.test(x, mu = 5).
⚠ Typische Falle. Mit dem z-Quantil 1.96 statt 2.365 wäre man zu großzügig: bei geschätztem σ ist die t-Verteilung breiter.

n unabhängige Messungen aus \(\Nor(\mu,\sigma^2)\), getestet wird der Erwartungswert. Ist σ bekannt → Z-Test; ist σ unbekannt (der Normalfall) → t-Test.

📘 Grundlage🔬 Anatomie: die standardisierte Teststatistik Z (σ bekannt)
\[ \Chg{Z}=\frac{\Mem{\bar X_n}-\Par{\mu_0}}{\Par{\sigma}/\sqrt n}=\frac{\text{beobachtet}-\text{erwartet}}{\text{Standardfehler}}\ \sim\ \Nor(0,1)\ \text{unter }H_0 \]
\(Z\)wie viele Standardfehler das Mittel vom Sollwert entfernt ist
\(\text{Verwerfen}\)\(|z|\ge z_{1-\alpha/2}\) (zweiseitig), \(z\ge z_{1-\alpha}\) (oben), \(z\le z_\alpha\) (unten)
\(z_{1-\alpha}\)Quantil der Standardnormal: die feste kritische Grenze, z. B. 1.645 (einseitig) oder 1.96 (zweiseitig) bei α = 0.05
📖 Vorlesen: „Z ist X-quer minus mü null, geteilt durch Sigma durch Wurzel n.“
📘 Grundlage
🎓 Prüfungs-Trainer. n = 25, x̄ = 51.2, σ = 4 bekannt, µ₀ = 50, H_A: µ > 50, α = 0.05. Berechne z und entscheide.
🗝️ ERKENNENσ bekannt → Z-Test, einseitig → 1.645.
⚙️ LÖSEN\(z=\tfrac{1.2}{0.8}=\Res{1.50}<1.645\) → nicht verwerfen.
🗣️ SAGEN„z ist 1.50, kleiner als 1.645, also können wir H₀ nicht verwerfen.“
📘 Grundlage👁️ Woran erkennbar? Verwerfungsbereich und Fehler 1. Art (Z-Test)
📘 Grundlage🔬 Anatomie: die Teststatistik T (σ unbekannt) und die t-Verteilung
\[ \Chg{T}=\frac{\Mem{\bar X_n}-\Par{\mu_0}}{\Mem{S_n}/\sqrt n}=\frac{\text{beobachtet}-\text{erwartet}}{\text{geschätzter Standardfehler}}\ \sim\ \Rule{t}_{\Idx{n-1}}\ \text{unter }H_0 \]
\(T\)wie Z, aber σ durch den Schätzer \(S_n\) ersetzt; diese zusätzliche Streuung macht T langschwänziger
\(t_{n-1}\)t-Verteilung mit n − 1 Freiheitsgraden (pro geschätztem Parameter einen „bezahlen“); für \(n\to\infty\) wird sie zur Standardnormal
\(\text{Verwerfen}\)\(|t|\ge t_{n-1,1-\alpha/2}\) (zweiseitig) usw.: gleiche Regel wie beim Z-Test, nur t-Quantile
📖 Vorlesen: „T ist X-quer minus mü null, geteilt durch S durch Wurzel n; unter H null t-verteilt mit n minus eins Freiheitsgraden.“
📘 Grundlage💡 Kernaussage: Der t-Test ist bei normalverteilten Daten der optimale Test. Weil man σ schätzen muss, nimmt man breitere t-Quantile statt z-Quantile: man ist vorsichtiger.
📘 Grundlage
🎓 Prüfungs-Trainer. n = 16, x̄ = 102, s = 6, µ₀ = 100, zweiseitig, α = 0.05. t und Entscheidung?
🗝️ ERKENNENσ unbekannt → t-Test, df = 15, Grenze 2.131.
⚙️ LÖSEN\(t=\tfrac{2}{1.5}=\Res{1.333}<2.131\) → nicht verwerfen.
🗣️ SAGEN„t ist 1.33, betragsmäßig kleiner als 2.131: wir verwerfen H₀ nicht.“
📘 Grundlage🧱 Bauplan: t-Test der Abfüllmaschine

Sollwert 1000 g, n = 10, x̄ = 1002.63, s = 1.23; H₀: μ = 1000, H_A: μ ≠ 1000, α = 0.05.

\[\begin{aligned} t &= \frac{1002.63-1000}{1.23/\sqrt{10}}=\Res{6.76} && \text{Teststatistik} \\ K &= (-\infty,-2.262]\cup[2.262,\infty) && t_{9,0.975}=2.262 \\ 6.76 &\ge 2.262\ \Rightarrow\ H_0\ \text{verwerfen} && \text{Entscheidung} \end{aligned}\]

Bei bekanntem σ = 1.23 wäre es ein Z-Test mit Grenze 1.96. Die Maschine ist nachweislich falsch kalibriert.

✚ Neu📋 t-Quantile \(t_{\text{df},\,q}\) (Formelsammlung)

Mit der Seite berechnet (unvollständige Beta-Funktion). Letzte Zeile ∞ = Standardnormal.

Code: t-Test Schritt für Schritt

R · t-TestBasis-R, vollständig lauffähig
1# t-Test für den Erwartungswert, Schritt für Schritt
2x <- c(5.1, 4.9, 5.6, 5.8, 5.3, 5.5, 5.2, 5.4)   # Messwerte
3mu0 <- 5; alpha <- 0.05                    # Sollwert und Niveau, zweiseitig
4n <- length(x)                             # Stichprobenumfang
5xbar <- mean(x); s <- sd(x)                # Mittel und Standardabweichung (n - 1)
6se <- s / sqrt(n)                          # geschätzter Standardfehler
7t <- (xbar - mu0) / se                     # Teststatistik: Abweichung in Standardfehlern
8krit <- qt(1 - alpha / 2, df = n - 1)      # kritischer Wert t_{n-1, 1-alpha/2}
9p <- 2 * (1 - pt(abs(t), df = n - 1))      # zweiseitiger P-Wert
10vi <- xbar + c(-1, 1) * krit * se          # Vertrauensintervall (Dualität)
11cat("t =", t, " krit =", krit, " p =", p, " verwerfen:", abs(t) >= krit, "\n")
12t.test(x, mu = mu0)                        # eingebaut: gleiche Zahlen
Python · t-Testnumpy / scipy / matplotlib, vollständig lauffähig
1# t-Test für den Erwartungswert, Schritt für Schritt
2import numpy as np
3from scipy import stats
4
5x = np.array([5.1, 4.9, 5.6, 5.8, 5.3, 5.5, 5.2, 5.4])   # Messwerte
6mu0, alpha = 5, 0.05                       # Sollwert und Niveau, zweiseitig
7n = len(x)                                 # Stichprobenumfang
8xbar, s = x.mean(), x.std(ddof=1)          # Mittel und Standardabweichung (n - 1)

10t = (xbar - mu0) / se                      # Teststatistik: Abweichung in Standardfehlern
11krit = stats.t.ppf(1 - alpha / 2, df=n - 1)   # kritischer Wert t_{n-1, 1-alpha/2}
12p = 2 * stats.t.sf(abs(t), df=n - 1)       # zweiseitiger P-Wert
13vi = xbar + np.array([-1, 1]) * krit * se  # Vertrauensintervall (Dualität)
14print(f"t = {t:.4f}  krit = {krit:.4f}  p = {p:.4f}  verwerfen: {abs(t) >= krit}")
15print(stats.ttest_1samp(x, mu0))           # eingebaut: gleiche Zahlen

7.3Eigenschaften von Tests: Macht und P-Wert

✚ Neu
Von null · Abschnitt 7.3Macht eines Z-Tests und nötiger Stichprobenumfang
Prüfungsaufgabe (für sich allein lösbar). Einseitiger Z-Test \(H_0:\mu=50\) gegen \(H_A:\mu>50\), σ = 4, n = 25, α = 0.05. (a) Ab welchem \(\bar x\) wird verworfen? (b) Wie groß ist die Macht, falls in Wahrheit μ = 52? (c) Wie groß muss n sein für eine Macht von 0.90? (d) Ein Versuch liefert z = 1.5. P-Wert?
Lösung von null, Schritt für Schritt
1
(a) Grenze auf der x̄-Skala. Verwerfen, wenn \(z\ge1.645\), also \(\bar x\ge50+1.645\cdot\tfrac{4}{5}=\Res{51.32}\).
2
(b) Macht: jetzt aus Sicht μ = 52. \[\begin{aligned} 1-\beta &= \PP_{\mu=52}(\bar X\ge51.32) && \text{Verwerfungsbereich bleibt} \\ &= 1-\Phi\Big(\frac{51.32-52}{0.8}\Big)=1-\Phi(-0.855) && \text{unter }\mu=52\text{ standardisiert} \\ &\approx \Res{0.804} && \text{kompakt: }1-\Phi\big(z_{1-\alpha}-\tfrac{\mu_1-\mu_0}{\sigma/\sqrt n}\big) \end{aligned}\]
3
(c) n für Macht 0.9. \[n\ge\Big(\frac{(z_{1-\alpha}+z_{0.9})\,\sigma}{\mu_1-\mu_0}\Big)^2=\Big(\frac{(1.645+1.282)\cdot4}{2}\Big)^2\approx34.3\ \Rightarrow\ n=\Res{35}\]
4
(d) P-Wert einseitig. \(p=\PP(Z\ge1.5)=1-\Phi(1.5)\approx\Res{0.067}>0.05\) → nicht verwerfen.
✔ Grenze x̄ ≥ 51.32; Macht ≈ 0.80; n = 35; p ≈ 0.067.
⚠ Typische Falle. Der P-Wert ist nicht die W'keit, dass H₀ stimmt. Er wird unter der Annahme berechnet, dass H₀ gilt.

Der Test kontrolliert den Fehler 1. Art über α. Aber wie gut findet er eine echte Abweichung? Das misst die Macht. Und der P-Wert fasst das Ergebnis in einer Zahl.

📘 Grundlage🔬 Anatomie: Macht (Power)
\[ \underbrace{1-\Par{\beta}(\theta)}_{\text{Macht}}=\PP\big(\text{Test verwirft }H_0\ \text{für}\ \theta\in H_A\big) \]
\(\beta(\theta)\)W'keit für einen Fehler 2. Art: H₀ beibehalten, obwohl θ gilt
\(1-\beta\)Macht: W'keit, eine echte Abweichung nachzuweisen; wächst mit Abstand θ − μ₀ und mit n
\(\text{Sicht}\)beim Niveau die Sicht von H₀; bei der Macht die eigene Sicht (ein bestimmtes θ ∈ H_A). Reine „Was-wäre-wenn“-Rechnung, keine Daten nötig
📖 Vorlesen: „Macht ist die W'keit, H null zu verwerfen, wenn in Wahrheit die Alternative gilt“, z. B. Münze, K = {9, 10}: unter p = 0.75 ist die Macht P(X ≥ 9) = 0.244.
📘 Grundlage
🎓 Prüfungs-Trainer. Einseitiger Z-Test, α = 0.05, Effekt d = 0.8σ, n = 25. Macht?
🗝️ ERKENNENMacht = 1 − Φ(z₁₋α − d√n).
⚙️ LÖSEN\(d\sqrt n=4\); \(1-\Phi(1.645-4)=\Phi(2.355)\approx\Res{0.991}\).
🗣️ SAGEN„Die Macht ist rund 99 Prozent.“
📘 Grundlage👁️ Woran erkennbar? die Macht als Fläche zweier Verteilungen
Erkennbar an: lila die Teststatistik unter H₀, blau unter der Alternative (verschoben um \(d\sqrt n\)). Der Verwerfungsbereich rechts der roten Grenze kommt allein aus H₀. Die grüne Fläche ist die Macht.
📘 Grundlage🔬 Anatomie: der P-Wert
\[ \Res{p}=\PP_{H_0}\big(\text{ein mindestens so extremes Ereignis wie das beobachtete}\big) \]
\(\text{Definition}\)das kleinste Niveau α, bei dem man H₀ gerade noch verwirft
\(\text{Entscheidung}\)\(p\le\alpha\Rightarrow\) verwerfen („signifikant“), sonst nicht. Enthält mehr Information als der reine Testentscheid
\(\text{Achtung}\)nicht die W'keit, dass H₀ stimmt
\(\text{Rechnen}\)diskret: Summe der W'keiten extremerer Ausgänge; stetig: Schwanzfläche. Münze x = 7: einseitig \(\PP_{p_0}(X\ge7)=0.172\)
📖 Vorlesen: „Der P-Wert ist die W'keit, unter H null etwas mindestens so Extremes zu sehen.“
📘 Grundlage
🎓 Prüfungs-Trainer. Zweiseitiger t-Test (df = 20) liefert t = 2.4. P-Wert und Entscheidung bei α = 0.05?
🗝️ ERKENNENZweiseitig → beide Schwänze.
⚙️ LÖSEN\(p=2\,\PP(T_{20}\ge2.4)\approx\Res{0.026}<0.05\) → verwerfen.
🗣️ SAGEN„Der P-Wert ist etwa 0.026, also verwerfen wir H₀ auf dem 5-Prozent-Niveau.“
📘 Grundlage👁️ Woran erkennbar? der P-Wert als Schwanzfläche
⚠ ✚ P-Hacking: Wer viele Tests macht und nur die signifikanten berichtet, findet bei α = 0.05 im Schnitt einen „Treffer“ pro 20 Tests, auch wenn nichts dahinter ist. Hypothese und α werden deshalb vor dem Blick auf die Daten festgelegt.

7.4Vertrauensintervalle und die Dualität zum Test

✚ Neu
Von null · Abschnitt 7.4Aus dem Vertrauensintervall mehrere Tests auf einmal ablesen
Prüfungsaufgabe (für sich allein lösbar). Für die acht Messwerte aus 7.2 (\(\bar x=5.35\), s = 0.2878, n = 8): (a) Bestimme das 95-%-Vertrauensintervall für μ. (b) Werden \(H_0:\mu=5\), \(H_0:\mu=5.2\), \(H_0:\mu=5.6\) zweiseitig bei α = 0.05 verworfen? (c) Fachlich relevant sind nur Abweichungen über 0.5 vom Sollwert 5. Ist das Ergebnis relevant?
Lösung von null, Schritt für Schritt
1
(a) Intervall mit t-Quantil. \[\begin{aligned} I &= \bar x\pm t_{7,0.975}\,\frac{s}{\sqrt n}=5.35\pm2.365\cdot0.1018 && \text{Rezept} \\ &= 5.35\pm0.241=\Res{[5.109;\ 5.591]} && \text{eingesetzt} \end{aligned}\]
2
(b) Dualität: μ₀ ∈ I ⇔ nicht verworfen. 5 ∉ I → verwerfen (wie in 7.2). 5.2 ∈ I → nicht verwerfen. 5.6 ∉ I (knapp) → verwerfen.
3
(c) Relevanz. Irrelevanter Bereich [4.5; 5.5]. Das VI [5.109; 5.591] ragt über 5.5 hinaus, liegt aber nicht ganz darüber: signifikant, Relevanz nicht gesichert.
✔ I = [5.11; 5.59]; μ₀ = 5 und 5.6 verworfen, 5.2 nicht; signifikant, aber Relevanz offen.

Der Test sagt für einen Sollwert ja/nein. Das Vertrauensintervall sammelt alle Sollwerte, die man nicht verwerfen würde: der volle Bereich plausibler Parameter.

📘 Grundlage🔬 Anatomie: Vertrauensintervall und Dualität
\[ \Res{I}=\{\Par{\mu_0}:\ H_0:\mu=\mu_0\ \text{wird nicht verworfen}\}\ \Longrightarrow\ I=\Mem{\bar X_n}\pm\frac{\Mem{S_n}}{\sqrt n}\,\Rule{t}_{n-1,1-\alpha/2} \]
\(\text{Dualität}\)\(\mu_0\in I\iff H_0:\mu=\mu_0\) wird nicht verworfen
\(\text{Überdeckung}\)\(\PP(I\ni\theta)=1-\alpha\): das zufällige Intervall fängt den wahren Wert in \((1-\alpha)\cdot100\) % der Wiederholungen
\(\text{Form}\)t-Test: \(\bar X\pm\frac{S}{\sqrt n}t_{n-1,1-\alpha/2}\). Z-Test: dasselbe mit σ und \(z_{1-\alpha/2}\)
📖 Vorlesen: „Das Vertrauensintervall ist X-quer plus/minus S durch Wurzel n mal das t-Quantil.“
📘 Grundlage📖 Informationsgehalt: Testentscheid ⪯ P-Wert ⪯ Vertrauensintervall. Das Intervall zeigt zugleich, welche H₀ verworfen werden und wie genau geschätzt wurde.
📘 Grundlage
🎓 Prüfungs-Trainer. Das 95-%-VI für µ ist [48.5, 53.5]. Wird H₀: µ = 50 verworfen? Und H₀: µ = 54?
🗝️ ERKENNENµ₀ im VI ⟺ nicht verworfen.
⚙️ LÖSEN50 ∈ I → nicht verworfen; 54 ∉ I → verworfen.
🗣️ SAGEN„50 liegt im Intervall, 54 außerhalb: direkt aus dem VI ablesbar.“
📘 Grundlage👁️ Woran erkennbar? VI ↔ Test-Dualität
Erkennbar an: feste Daten (x̄ = 1002.63, s = 1.23, n = 10). Liegt μ₀ im blauen Band, wird nicht verworfen (grün), sonst verworfen (rot). An der Bandgrenze ist der P-Wert genau α.
📘 Grundlage🧱 Bauplan: 95-%-VI für die Abfüllmaschine \[\begin{aligned} I &= 1002.63\pm\frac{1.23}{\sqrt{10}}\cdot2.262=\Res{[1001.75;\ 1003.51]} && \text{Intervall} \\ 1000 &\notin I\ \Rightarrow\ H_0:\mu=1000\ \text{verwerfen} && \text{Testentscheid abgelesen} \end{aligned}\]
📘 Grundlage🔬 Anatomie: statistische Signifikanz ≠ fachliche Relevanz
\(\text{Signifikanz}\)bei sehr großem n wird jede noch so kleine Abweichung signifikant; signifikant heißt nur: statistisch nachweisbar
\(\text{Relevanz}\)ob eine Abweichung fachlich zählt, legt Fachwissen fest (Relevanzgrenze δ, irrelevanter Bereich \(\mu_0\pm\delta\))
\(\text{Beurteilen}\)VI gegen den Relevanzbereich halten: VI [1001.75; 1003.51] bei irrelevantem Bereich [995; 1005] → signifikant, aber nicht relevant
📖 Vorlesen: „Statistik und Fachwissen kombinieren: das Vertrauensintervall gegen den Relevanzbereich halten.“

7.5Tests bei nicht normalverteilten Daten

✚ Neu
Von null · Abschnitt 7.5Vorzeichen- und Wilcoxon-Test für zehn Füllmengen
Prüfungsaufgabe (für sich allein lösbar). Zehn Füllmengen (g): 1002.1, 1003.4, 999.2, 1001.8, 1004.0, 1002.9, 1000.6, 1003.1, 1001.2, 1002.5. Test von \(H_0\): Median = 1000 gegen ≠, α = 0.05. (a) Vorzeichen-Test. (b) Wilcoxon-Test (für n = 10 zweiseitig K = {W ≤ 8} ∪ {W ≥ 47}).
Lösung von null, Schritt für Schritt
1
Abweichungen \(d_i=x_i-1000\). 2.1, 3.4, −0.8, 1.8, 4.0, 2.9, 0.6, 3.1, 1.2, 2.5.
2
(a) Vorzeichen. \(Q\) = Anzahl positiver = 9. Unter H₀: \(Q\sim\Bin(10,0.5)\). \(p=2\,\PP(Q\ge9)=2(10+1)/1024=\Res{0.0215}<0.05\) → verwerfen.
3
(b) Ränge der Beträge. Sortierte |d|: 0.6 (R1), 0.8 (R2), 1.2 (R3), 1.8 (R4), 2.1 (R5), 2.5 (R6), 2.9 (R7), 3.1 (R8), 3.4 (R9), 4.0 (R10). Nur 0.8 gehört zu einem negativen d.
4
(b) W = Rangsumme der positiven. \(W=55-2=\Res{53}\ge47\) → verwerfen (Software: p ≈ 0.0059).
✔ Vorzeichen: Q = 9, p ≈ 0.022; Wilcoxon: W = 53, p ≈ 0.006; beide verwerfen (t-Test: p ≈ 0.0013).

Sind die Daten nicht normal, braucht man Tests mit schwächeren Annahmen. Sie testen den Median und können dann viel besser sein als der t-Test.

✚ Neu🔬 Anatomie: Vorzeichen-Test\Par{\mu_0}\}\ \sim\ \Bin(n,\ 0.5)\quad\text{unter }H_0:\text{Median}=\mu_0" src="G">
\(Q\)Anzahl positiver Vorzeichen von \(X_i-\mu_0\); nur die Vorzeichen zählen
\(\text{Idee}\)stimmt μ₀ als Median, liegt jeder Wert mit W'keit 0.5 darüber → Binomialtest aus 7.1!
\(\text{Vor-/Nachteil}\)keine Verteilungsannahme außer dem Median; verschenkt aber die Information der Beträge
📖 Vorlesen: „Q zählt die Werte über mü null; unter H null ist Q binomial mit n und einhalb.“
✚ Neu🔬 Anatomie: Wilcoxon-Test (der Kompromiss)\mu_0" src="G">
\(W\)Summe der Ränge der Abstände, nur für die Werte über μ₀
\(\text{Annahme}\)nur eine um μ₀ symmetrische Verteilung; W zu groß oder zu klein → verwerfen (Schranken aus Tabellen)
\(\text{Praxis}\)meist dem t- und Vorzeichen-Test vorzuziehen; nur bei sehr gut normalen Daten (Normalplot!) ist der t-Test voll tauglich
📖 Vorlesen: „W ist die Summe der Ränge der Beträge, gezählt nur bei positiven Abweichungen.“
📘 Grundlage
🎓 Prüfungs-Trainer. Kleine Stichprobe, Normalplot zeigt klare Abweichungen. Median-Test gesucht. Welcher Test?
🗝️ ERKENNENNicht normal → t-Test riskant; Vorzeichen verschenkt Information.
⚙️ LÖSENWilcoxon: verteilungsfrei (Symmetrie), nutzt Ränge, meist mehr Macht.
🗣️ SAGEN„Ich nehme Wilcoxon: verteilungsfrei, nutzt die Ränge und ist bei nicht-normalen Daten am zuverlässigsten.“
📘 Grundlage🎯 Drei Tests, ein Datensatz (Grundlage: Abfüllmaschine)
TestnutztStatistikP-WertEntscheid
t-Testexakte Werte (Normal!)t = 6.76< 0.001verwerfen

Mehr genutzte Information → i. d. R. kleinerer P-Wert, mehr Macht. Aber der t-Test setzt Normalverteilung voraus; sonst ist Wilcoxon die sichere Wahl.

R · Vorzeichen, Wilcoxon, MachtBasis-R, vollständig lauffähig
1# Vorzeichen-Test, Wilcoxon-Test und Macht (Power)
2y <- c(1002.1, 1003.4, 999.2, 1001.8, 1004.0, 1002.9, 1000.6, 1003.1, 1001.2, 1002.5)
3d <- y - 1000                              # Abweichungen vom Sollwert
4Q <- sum(d > 0)                            # Vorzeichen-Test: Anzahl positiver Vorzeichen
5binom.test(Q, length(d), 0.5)              # Q ~ Bin(n, 0.5) unter H0, p = 0.0215
6W <- sum(rank(abs(d))[d > 0])              # Wilcoxon: Rangsumme der positiven Abweichungen
7W; wilcox.test(y, mu = 1000)               # W = 53, p = 0.0059
8t.test(y, mu = 1000)$p.value               # t-Test zum Vergleich
9# Macht des einseitigen Z-Tests: sigma = 4, n = 25, mu0 = 50, wahres mu1 = 52
101 - pnorm(qnorm(0.95) - (52 - 50) / (4 / sqrt(25)))    # 0.804
11power.t.test(delta = 2, sd = 4, power = 0.9, type = "one.sample", alternative = "one.sided")   # nötiges n (t-Version)
Python · Vorzeichen, Wilcoxon, Machtnumpy / scipy / matplotlib, vollständig lauffähig
1# Vorzeichen-Test, Wilcoxon-Test und Macht (Power)
2import numpy as np
3from scipy import stats
4
5y = np.array([1002.1, 1003.4, 999.2, 1001.8, 1004.0, 1002.9, 1000.6, 1003.1, 1001.2, 1002.5])
6d = y - 1000                               # Abweichungen vom Sollwert
7Q = int(np.sum(d > 0))                     # Vorzeichen-Test: Anzahl positiver Vorzeichen
8print(stats.binomtest(Q, len(d), 0.5).pvalue)             # Q ~ Bin(n, 0.5) unter H0, p = 0.0215
9W = stats.rankdata(np.abs(d))[d > 0].sum() # Wilcoxon: Rangsumme der positiven Abweichungen
10print(W, stats.wilcoxon(d).pvalue)         # W = 53, p = 0.0059 (scipy meldet min(W+, W-) = 2)
11print(stats.ttest_1samp(y, 1000).pvalue)   # t-Test zum Vergleich
12# Macht des einseitigen Z-Tests: sigma = 4, n = 25, mu0 = 50, wahres mu1 = 52
13print(stats.norm.sf(stats.norm.ppf(0.95) - (52 - 50) / (4 / np.sqrt(25))))   # 0.804

📐 Schema: statistischer Test in 6 Schritten

  1. Modell für die Daten wählen.
  2. Nullhypothese \(H_0:\theta=\theta_0\) festlegen.
  3. Alternative (zwei-/einseitig) spezifizieren: sie bestimmt die Form von K.
  4. Niveau α wählen (0.05 oder 0.01).
  5. Verwerfungsbereich K unter H₀ konstruieren, sodass P(Fehler 1. Art) ≤ α.
  6. Erst jetzt die Teststatistik betrachten: in K → verwerfen; sonst H₀ belassen (kein Beweis für H₀).

DiskretBinomialtest: n = 20, p₀ = 0.1, x = 5.
Verdict: K = {5, …, 20}, x ∈ K → verwerfen.
Beispiel 2 · mittel 📘 Grundlage
Stetigt-Test: x̄ = 1002.63, s = 1.23, n = 10.
Verdict: t = 6.76 > 2.262 → verwerfen.
Beispiel 3 · schwer 📘 Grundlage
Dual/robust95-%-VI [1001.75; 1003.51].
Verdict: ∌ 1000 → verwerfen; robust bestätigt durch Wilcoxon (p = 0.004).
