Mehrdimensionale Verteilungen

Zwei Größen zugleich: die gemeinsame Verteilung, ihre Rand- und bedingten Verteilungen, der Erwartungswert von Kombinationen und die zentrale Kennzahl der Abhängigkeit, Kovarianz und Korrelation, bis zur zweidimensionalen Normalverteilung und der Summe zweier Zufallsvariablen (Faltung).

📘 Grundlage🔗 Roter Faden: Alles Eindimensionale aus Kap. 1–2 kommt wieder, nur mit einem zweiten Buchstaben Y daneben. „Rand“ heißt: die andere Variable wegsummieren/wegintegrieren; „bedingt“ heißt: eine Variable festhalten. Neu ist nur die Frage, wie stark X und Y zusammenhängen.

4.0Master-Anatomie

✚ Neu🔬 Anatomie: die Quelle von allem: die gemeinsame Verteilung
\[ \underbrace{\PP(\mX=x,\mY=y)}_{\text{gemeinsam}}\ \xrightarrow{\Chg{\sum_y}}\ \underbrace{\PP(\mX=x)}_{\text{Rand}}\qquad \underbrace{\PP(\mY=y\given\mX=x)=\frac{\PP(\mX=x,\mY=y)}{\PP(\mX=x)}}_{\text{bedingt}}\qquad \underbrace{\Cov(\mX,\mY)=\EE[\mX\mY]-\EE[\mX]\EE[\mY]}_{\text{Abhängigkeit}} \]
\(\PP(\mX=x,\mY=y)\)die ganze Information über das Paar: eine Tabelle (diskret) oder eine Fläche \(\ff_{X,Y}(x,y)\) (stetig)
\(\Chg{\sum_y}\)Rand: die andere Variable wegsummieren (stetig: wegintegrieren)
\(\given\)bedingt: eine Variable festhalten und neu normieren
\(\Cov\)eine Zahl für die lineare Abhängigkeit
📖 Vorlesen: „Aus der gemeinsamen Verteilung folgen Rand, bedingte Verteilung und Kovarianz; umgekehrt geht das nur bei Unabhängigkeit.“
📘 Grundlage🎓 Das agnostische Spitzenwerkzeug
  1. ERKENNEN: Ist die gemeinsame Verteilung gegeben (Tabelle/Dichte)? Gesucht: Rand · bedingt · Unabhängigkeit · Cov/Corr · E/Var einer Kombination · Verteilung einer Summe?
  2. WÄHLEN: Rand → andere Variable wegsummieren/-integrieren · bedingt → gemeinsam ÷ Rand · Unabhängigkeit → gemeinsam = Produkt der Ränder? · Cov → \(\EE[XY]-\EE[X]\EE[Y]\) · Var(X±Y) → Var(X)+Var(Y)±2Cov · Summendichte → Faltung.
  3. RECHNEN: Formel einsetzen; Cov/Corr immer über die praktische Formel; E/Var einer Linearkombination direkt mit den Rechenregeln (ohne Umweg über die gemeinsame Dichte).
  4. ARTIKULIEREN: „Die gemeinsame Verteilung liefert [Rand/bedingt]; die Abhängigkeit misst Cov = […], Corr = […]; für die Kombination gilt E = […], Var = […].“
📘 Grundlage🧭 Die 6 Leitfragen dieses Kapitels
  1. Wie hängen zwei Größen zusammen? Die gemeinsame Verteilung \(\PP(\mX=x,\mY=y)\) bzw. \(\ff_{X,Y}(x,y)\).
  2. Wie komme ich zur einzelnen Größe zurück? Die Randverteilung.
  3. Was weiß ich über Y, wenn X bekannt ist? Die bedingte Verteilung.
  4. Sind X und Y unabhängig? Genau dann, wenn gemeinsam = Produkt der Ränder.
  5. Wie stark und in welche Richtung hängen sie linear zusammen? Cov und \(\Corr\in[-1,1]\).
  6. Wie verhält sich eine Summe/Kombination? \(\EE[a+bX+cY]\) und \(\Var(X+Y)=\Var(X)+\Var(Y)+2\Cov\).

\[ \pf(x,y)=\PP(\mX=x,\ \mY=y),\qquad x\in\WW_X,\ y\in\WW_Y \]
\(\PP(\mX=x,\mY=y)\)die W'keit, dass X und Y gleichzeitig ihre Werte annehmen: eine ganze Tabelle von Wahrscheinlichkeiten
\(\{\mX=x,\mY=y\}\)Kurzschreibweise für \(\{\mX=x\}\capc\{\mY=y\}\): beide Ereignisse zugleich

\[ \PP(\mX=x)=\sum_{y\in\WW_Y}\underbrace{\PP(\mX=x,\mY=y)}_{\text{alle y durchlaufen}} \]
\(\text{Rand}\)die „einzelne“ Verteilung von X allein. In der Tabelle: die Zeilen- bzw. Spaltensummen (der „Rand“)

\[ \PP(\mX=x\given\mY=y)=\frac{\PP(\mX=x,\mY=y)}{\PP(\mY=y)},\qquad \EE[\mY\given\mX=x]=\sum_y y\,\PP(\mY=y\given\mX=x) \]

Code: eine Tabelle vollständig auswerten

Eingabe: x-Werte ; y-Werte ; Tabelle zeilenweise. Der Tracer bildet die Ränder, E[X], E[Y], dann E[XY] Feld für Feld, Cov, Corr und prüft die Unabhängigkeit.

R · Tabelle auswertenBasis-R, vollständig lauffähig
1# Gemeinsame Verteilung als Tabelle: Ränder, E, Kovarianz, Korrelation
2x <- c(0, 1, 2)                            # Werte von X (Zeilen)
3y <- c(0, 1)                               # Werte von Y (Spalten)
4P <- matrix(c(0.10, 0.20,                  # P(X = x_i, Y = y_j), zeilenweise
5              0.15, 0.25,
6              0.05, 0.25), nrow = 3, byrow = TRUE)
7pX <- rowSums(P)                           # Randverteilung von X: Zeilensummen
8pY <- colSums(P)                           # Randverteilung von Y: Spaltensummen
9EX <- sum(x * pX); EY <- sum(y * pY)       # Erwartungswerte aus den Rändern
10EXY <- 0                                   # E[XY] braucht die gemeinsame Tabelle
11for (i in seq_along(x)) for (j in seq_along(y))   # jedes Feld der Tabelle
12  EXY <- EXY + x[i] * y[j] * P[i, j]       # Wert x*y mal Wahrscheinlichkeit
13covXY <- EXY - EX * EY                     # Kovarianz, praktische Formel
14VX <- sum(x^2 * pX) - EX^2; VY <- sum(y^2 * pY) - EY^2   # Varianzen
15rho <- covXY / sqrt(VX * VY)               # Korrelation
16unabh <- isTRUE(all.equal(P, outer(pX, pY)))   # gemeinsam = Produkt der Ränder?
17cat("Cov =", covXY, " Corr =", rho, " unabhängig:", unabh, "\n")
Python · Tabelle auswertennumpy / scipy / matplotlib, vollständig lauffähig
1# Gemeinsame Verteilung als Tabelle: Ränder, E, Kovarianz, Korrelation
2import numpy as np
3
4x = np.array([0, 1, 2])                    # Werte von X (Zeilen)
5y = np.array([0, 1])                       # Werte von Y (Spalten)
6P = np.array([[0.10, 0.20],                # P(X = x_i, Y = y_j), zeilenweise
7              [0.15, 0.25],
8              [0.05, 0.25]])
9pX = P.sum(axis=1)                         # Randverteilung von X: Zeilensummen
10pY = P.sum(axis=0)                         # Randverteilung von Y: Spaltensummen
11EX, EY = np.sum(x * pX), np.sum(y * pY)    # Erwartungswerte aus den Rändern
12EXY = 0.0                                  # E[XY] braucht die gemeinsame Tabelle
13for i in range(len(x)):                    # jedes Feld der Tabelle
14    for j in range(len(y)):
15        EXY += x[i] * y[j] * P[i, j]       # Wert x*y mal Wahrscheinlichkeit
16covXY = EXY - EX * EY                      # Kovarianz, praktische Formel
17VX = np.sum(x**2 * pX) - EX**2; VY = np.sum(y**2 * pY) - EY**2   # Varianzen
18rho = covXY / np.sqrt(VX * VY)             # Korrelation
19unabh = np.allclose(P, np.outer(pX, pY))   # gemeinsam = Produkt der Ränder?
20print("Cov =", covXY, " Corr =", rho, " unabhängig:", unabh)

4.1.2Stetiger Fall: die gemeinsame Dichte

✚ Neu
Von null · Abschnitt 4.1.2Dichte f(x, y) = x + y auf dem Einheitsquadrat
Prüfungsaufgabe (für sich allein lösbar). \(\ff_{X,Y}(x,y)=x+y\) für \(0\le x,y\le1\), sonst 0. (a) Zeige, dass dies eine Dichte ist. (b) Bestimme die Randdichte \(\ff_X\). (c) Berechne \(\PP(\mX\le\tfrac12,\mY\le\tfrac12)\) und \(\PP(\mX+\mY\le1)\). (d) Sind X und Y unabhängig?
Lösung von null, Schritt für Schritt
1
(a) Volumen = 1. \[\begin{aligned} \iint_{[0,1]^2}(x+y)\dd x\dd y &= \int_0^1\Big[\tfrac{x^2}{2}+xy\Big]_{x=0}^{1}\dd y=\int_0^1\big(\tfrac12+y\big)\dd y && \text{erst nach x integrieren} \\ &= \tfrac12+\tfrac12=1 && \text{und } f\ge0\ \checkmark \end{aligned}\]
2
(b) y herausintegrieren. \(\ff_X(x)=\int_0^1(x+y)\dd y=\Res{x+\tfrac12}\) für \(0\le x\le1\).
3
(c) Doppelintegrale über Bereiche. \[\begin{aligned} \PP(\mX\le\tfrac12,\mY\le\tfrac12) &= \int_0^{1/2}\!\!\int_0^{1/2}(x+y)\dd x\dd y=2\cdot\tfrac12\cdot\tfrac18=\Res{\tfrac18} && \text{Quadrat, symmetrisch} \\ \PP(\mX+\mY\le1) &= \int_0^1\!\!\int_0^{1-x}(x+y)\dd y\dd x=\int_0^1\big(\tfrac12-\tfrac{x^2}{2}\big)\dd x=\Res{\tfrac13} && \text{Dreieck unter der Diagonale} \end{aligned}\]
4
(d) Produkt der Ränder? Aus Symmetrie \(\ff_Y(y)=y+\tfrac12\). \(\ff_X(x)\ff_Y(y)=(x+\tfrac12)(y+\tfrac12)\ne x+y\) (z. B. bei (0, 0): 0.25 ≠ 0) → abhängig.
✔ Dichte ✓; \(\ff_X(x)=x+\tfrac12\); P = 1/8 und 1/3; abhängig.
📘 Grundlage🔬 Anatomie: gemeinsame Dichte, Randdichte, bedingte Dichte
\[ \PP((\mX,\mY)\in \Cond{A})=\iint_{\Cond{A}}\ff_{X,Y}(x,y)\dd x\dd y,\qquad \ff_X(x)=\int_{-\infty}^{\infty}\ff_{X,Y}(x,y)\dd y,\qquad \ff_{Y\mid X=x}(y)=\frac{\ff_{X,Y}(x,y)}{\ff_X(x)} \]
\(\ff_{X,Y}(x,y)\)die gemeinsame Dichte: W'keit pro Fläche. P über einen Bereich A = Volumen unter der Dichtefläche (Doppelintegral)
\(\ff_X\)Randdichte: die andere Variable herausintegrieren (stetiges Pendant zum Wegsummieren)
\(\ff_{Y\mid X=x}\)bedingte Dichte: ein Querschnitt der Fläche bei festem x, umskaliert, damit er sich zu 1 integriert
\(\text{unabhängig}\iff\)\(\ff_{X,Y}(x,y)=\ff_X(x)\ff_Y(y)\): dann genügen die eindimensionalen Dichten
📖 Vorlesen: „Die W'keit, dass das Paar in A liegt, ist das Doppelintegral der gemeinsamen Dichte über A; die Randdichte von X erhält man durch Herausintegrieren von y.“
📘 Grundlage
🎓 Prüfungs-Trainer. \(\ff_{X,Y}(x,y)=c\) konstant auf \([0,1]^2\). Bestimme c und \(\PP(\mX<0.5)\).
🗝️ ERKENNENDichte über den ganzen Bereich integriert = 1 ⟹ c. Für P(X<0.5) die Randdichte nutzen.
⚙️ LÖSENFläche = 1 ⟹ \(c=\Res{1}\). \(\ff_X(x)=1\) auf [0,1] ⟹ \(\PP(\mX<0.5)=\Res{0.5}\).
🗣️ SAGEN„Die Konstante ist 1 (Einheitsvolumen), und P(X<0.5)=0.5: X ist gleichverteilt.“
📘 Grundlage📌 Beispiel: zwei Lebensdauern (Exp), P(Y < X)

Zwei unabhängige Maschinen: \(\mX\sim\Expo(\Par{\lambda_1})\), \(\mY\sim\Expo(\Par{\lambda_2})\). Wegen Unabhängigkeit ist die gemeinsame Dichte das Produkt \(\lambda_1e^{-\lambda_1x}\lambda_2e^{-\lambda_2y}\). Wie wahrscheinlich läuft Maschine 1 länger?

\[\begin{aligned} \PP(\mY\Cond{<}\mX) &= \int_0^\infty\lambda_1e^{-\lambda_1x}\Big(\int_0^x\lambda_2e^{-\lambda_2y}\dd y\Big)\dd x && \text{Bereich }yAnschaulich: die „schnellere“ Maschine (größeres λ, kürzere Lebensdauer) fällt eher zuerst aus.

4.2Erwartungswert bei mehreren Zufallsvariablen

✚ Neu
Von null · Abschnitt 4.3Cov, Corr und Var(X ± Y) aus der Tabelle
Prüfungsaufgabe (für sich allein lösbar). Weiter mit der Tabelle aus 4.1 (\(\EE[\mX]=1\), \(\EE[\mY]=0.7\), \(\EE[\mX\mY]=0.75\)). Berechne (a) \(\Cov(\mX,\mY)\), (b) \(\Var(\mX)\), \(\Var(\mY)\), \(\Corr(\mX,\mY)\), (c) \(\Var(\mX+\mY)\) und \(\Var(\mX-\mY)\), (d) \(\Cov(3\mX+1,\,-2\mY)\).
Lösung von null, Schritt für Schritt
1

2
(b) Varianzen und Korrelation. \[\begin{aligned} \Var(\mX) &= \EE[\mX^2]-\EE[\mX]^2=(0.4+4\cdot0.3)-1=0.6 && \EE[X^2]=1.6 \\ \Var(\mY) &= 0.7-0.49=0.21 && \text{Bernoulli: }p(1-p) \\ \Res{\rho} &= \frac{0.05}{\sqrt{0.6\cdot0.21}}=\frac{0.05}{0.355}\approx\Res{0.141} && \text{schwacher positiver Zusammenhang} \end{aligned}\]
3
(c) Varianz von Summe und Differenz. \[\begin{aligned} \Var(\mX+\mY) &= 0.6+0.21+2\cdot0.05=\Res{0.91} && +2\Cov \\ \Var(\mX-\mY) &= 0.6+0.21-2\cdot0.05=\Res{0.71} && -2\Cov \end{aligned}\]

✔ Cov = 0.05, Var(X) = 0.6, Var(Y) = 0.21, ρ ≈ 0.141, Var(X+Y) = 0.91, Var(X−Y) = 0.71, Cov(3X+1, −2Y) = −0.3.
⚠ Typische Falle. \(\Var(\mX-\mY)=\Var(\mX)-\Var(\mY)\) ist falsch: Varianzen werden immer addiert, nur der Kovarianz-Term wechselt das Vorzeichen.

Die ganze gemeinsame Verteilung ist kompliziert. Oft genügt eine Kennzahl für die (lineare) Abhängigkeit: die Kovarianz, bzw. standardisiert die Korrelation.

📘 Grundlage🔬 Anatomie: Kovarianz Cov(X,Y)
\[ \Res{\Cov(\mX,\mY)}=\EE\big[(\mX-\mu_X)(\mY-\mu_Y)\big]\ \overset{\text{praktisch}}{=}\ \EE[\mX\mY]-\EE[\mX]\,\EE[\mY] \]
\(\Cov(\mX,\mY)\)misst, ob X und Y gemeinsam vom Mittel abweichen. Positiv → wachsen zusammen, negativ → gegenläufig, 0 → kein linearer Zusammenhang
\(\text{praktisch}\)\(\EE[XY]-\EE[X]\EE[Y]\): meist der schnellste Rechenweg (analog zu \(\Var=\EE[X^2]-\EE[X]^2\))
\(\text{Spezialfälle}\)\(\Cov(\mX,\mX)=\Var(\mX)\); bei Unabhängigkeit \(\EE[XY]=\EE[X]\EE[Y]\Rightarrow\Cov=0\)
📖 Vorlesen: „Kovarianz gleich Erwartungswert von X mal Y minus Erwartungswert von X mal Erwartungswert von Y.“
📘 Grundlage
🎓 Prüfungs-Trainer. \(\EE[\mX\mY]=10\), \(\EE[\mX]=2\), \(\EE[\mY]=4\). Berechne \(\Cov(\mX,\mY)\).
🗝️ ERKENNENCov aus E[XY] → praktische Formel.
⚙️ LÖSEN\(10-2\cdot4=\Res{2}\).
🗣️ SAGEN„Die Kovarianz ist E[XY]−E[X]E[Y]=10−8=2: positiver Zusammenhang.“
📘 Grundlage🔬 Anatomie: Korrelation Corr(X,Y) = ρ
\[ \Res{\Corr(\mX,\mY)}=\Par{\rho_{XY}}=\frac{\Cov(\mX,\mY)}{\sigma_X\,\sigma_Y}\in[-1,1] \]
\(\rho\)die standardisierte Kovarianz: dimensionslos, immer in [−1, 1]. Betrag = Stärke, Vorzeichen = Richtung
\(\pm1\)\(\rho=+1\iff\mY=a+b\mX\ (b>0)\); \(\rho=-1\iff b<0\): perfekte Gerade
\(\rho=0\)unkorreliert: kein linearer Zusammenhang (ein nichtlinearer kann trotzdem bestehen!)
📖 Vorlesen: „Korrelation gleich Kovarianz geteilt durch das Produkt der beiden Standardabweichungen.“
📘 Grundlage
🎓 Prüfungs-Trainer. \(\Cov(\mX,\mY)=2\), \(\sigma_X=2\), \(\sigma_Y=5\). Berechne die Korrelation.
🗝️ ERKENNENKorrelation = Kovarianz standardisieren.
⚙️ LÖSEN\(\rho=\tfrac{2}{2\cdot5}=\Res{0.2}\).
🗣️ SAGEN„Corr=Cov/(σ_X σ_Y)=2/10=0.2: schwacher positiver linearer Zusammenhang.“
📘 Grundlage🧱 Bauplan: Cov und Corr aus einer 2×2-Tabelle

(X, Y) beide in {0, 1}: P(0,0)=0.4, P(0,1)=0.1, P(1,0)=0.2, P(1,1)=0.3.

\[\begin{aligned} \EE[\mX] &= 0.5,\quad\EE[\mY]=0.4,\quad\EE[\mX\mY]=1\cdot1\cdot0.3=0.3 && \text{Ränder und E-Werte} \\ \Cov(\mX,\mY) &= 0.3-0.5\cdot0.4=\Res{0.1} && \text{praktische Formel} \\ \Var(\mX) &= 0.25,\quad\Var(\mY)=0.24\ \Rightarrow\ \rho=\frac{0.1}{\sqrt{0.25\cdot0.24}}\approx\Res{0.408} && \text{Korrelation} \end{aligned}\]
⚠ unkorreliert ≠ unabhängig. Es gilt nur die eine Richtung: \(\mX,\mY\) unabhängig \(\Longrightarrow\Corr(\mX,\mY)=0\). Die Umkehrung ist falsch: Corr = 0 heißt nur „kein linearer Zusammenhang“. Beispiel: \(\mX\) gleichverteilt auf \(\{-1,0,1\}\), \(\mY=\mX^2\): \(\Cov=\EE[X^3]-\EE[X]\EE[X^2]=0-0=0\), aber Y ist durch X festgelegt. Einzige Ausnahme: die zweidimensionale Normalverteilung (4.4). 📘 Grundlage
📘 Grundlage🔧 Rechenregeln: Kovarianz, Korrelation, Varianz der Summe
\(\text{bilinear}\)\(\Cov(a\mX,b\mY)=ab\,\Cov(\mX,\mY)\); Cov zieht aus jeder Linearkombination die Koeffizienten heraus
\(\text{Verschiebung}\)\(\Cov(a+b\mX,\ c+d\mY)=bd\,\Cov(\mX,\mY)\): Konstanten fallen weg
\(\text{symmetrisch}\)\(\Cov(\mX,\mY)=\Cov(\mY,\mX)\)
\(\Var(\mX+\mY)\)\(=\Var(\mX)+\Var(\mY)+2\Cov(\mX,\mY)\): der Zusatzterm 2·Cov ist neu gegenüber Kap. 2!
\(\text{unkorreliert}\)\(\Cov=0\Rightarrow\Var(\mX+\mY)=\Var(\mX)+\Var(\mY)\)
\(\Corr(a+b\mX,\cdot)\)\(=\operatorname{sign}(b)\Corr(\mX,\cdot)\): Korrelation ist unabhängig von Maßeinheiten
✚ Neu🔍 Herleitung Var(X + Y) \[\begin{aligned} \Var(\mX+\mY) &= \EE\big[(\mX+\mY-\mu_X-\mu_Y)^2\big] && \text{Definition} \\ &= \EE\big[((\mX-\mu_X)+(\mY-\mu_Y))^2\big] && \text{umsortiert} \\ &= \EE[(\mX-\mu_X)^2]+\EE[(\mY-\mu_Y)^2]+2\,\EE[(\mX-\mu_X)(\mY-\mu_Y)] && \text{binomische Formel, Linearität} \\ &= \Var(\mX)+\Var(\mY)+2\Cov(\mX,\mY) && \text{Definitionen eingesetzt} \end{aligned}\]
📘 Grundlage
🎓 Prüfungs-Trainer. \(\Var(\mX)=3\), \(\Var(\mY)=5\), \(\Cov(\mX,\mY)=1\). Berechne \(\Var(\mX+\mY)\) und \(\Var(\mX-\mY)\).
🗝️ ERKENNENVarianz einer Summe → +2Cov; einer Differenz → −2Cov.
⚙️ LÖSEN\(3+5+2=\Res{10}\), \(3+5-2=\Res{6}\).
🗣️ SAGEN„Var(X+Y)=3+5+2·1=10 und Var(X−Y)=3+5−2·1=6.“
📘 Grundlage🧱 Bauplan: Var(X+Y) und Var(X−Y)

Gegeben: Var(X) = 4, Var(Y) = 9, Cov(X, Y) = 2.

\[\begin{aligned} \Var(\mX+\mY) &= 4+9+2\cdot2=\Res{17} && \text{Summe} \\ \Var(\mX-\mY) &= 4+9-2\cdot2=\Res{9} && \text{Differenz: }\Cov(\mX,-\mY)=-\Cov(\mX,\mY) \end{aligned}\]
📘 Grundlage👁️ Woran erkennbar? Var(X ± Y)-Explorer
Erkennbar an: 2·Cov hebt die Varianz der Summe und senkt die der Differenz. Der Regler steuert ρ, so bleibt \(|\Cov|\le\sqrt{\Var(X)\Var(Y)}\) automatisch erfüllt.

📘 Grundlage🔬 Anatomie: 2D-Normal und Kovarianzmatrix
\[ \Rule{\Sigma}=\begin{pmatrix}\Cov(\mX,\mX)&\Cov(\mX,\mY)\\\Cov(\mY,\mX)&\Cov(\mY,\mY)\end{pmatrix}=\begin{pmatrix}\Par{\sigma_X^2}&\Cov(\mX,\mY)\\\Cov(\mX,\mY)&\Par{\sigma_Y^2}\end{pmatrix} \]
\(\text{bestimmt durch}\)die Ränder \(\mu_X,\sigma_X^2\) und \(\mu_Y,\sigma_Y^2\), plus die Kovarianz: mehr braucht man nicht
\(\Sigma\)verpackt Varianzen (Diagonale) und Kovarianz (Nebendiagonale) in einer symmetrischen Matrix
\(\text{Konturlinien}\)Höhenlinien der Dichte sind Ellipsen: je größer \(|\rho|\), desto schmaler um eine Gerade
📖 Vorlesen: „Sigma hat die Varianzen auf der Diagonale und die Kovarianz daneben.“
📘 Grundlage⭐ Die Ausnahme von der Regel: Bei der 2D-Normalverteilung gilt, anders als sonst, auch die Umkehrung: unkorreliert (ρ = 0) ⟹ unabhängig.
📘 Grundlage

🗣️ SAGEN„Σ hat 4 und 9 auf der Diagonale, 3 daneben; die Korrelation ist 3/(2·3)=0.5.“
📘 Grundlage👁️ Woran erkennbar? Konturlinien und Punktwolke bei wachsendem ρ
Erkennbar an: bei ρ = 0 ist die Wolke rund; je näher ρ an ±1, desto mehr legt sie sich um eine Gerade. Die Gerade \(\EE[Y\given X=x]\) ist flacher als die Hauptachse der Ellipse („Regression zur Mitte“).
📘 Grundlage👁️ Woran erkennbar? unkorreliert ≠ unabhängig
Erkennbar an: beide Wolken haben Corr ≈ 0. Links: unabhängig (rund). Rechts: Punkte auf einem Kreis, klar abhängig, aber ohne linearen Zusammenhang. Die Korrelation „sieht“ nur Geraden.

4.5Dichte einer Summe zweier Zufallsvariablen

✚ Neu
Von null · Abschnitt 4.5Augensumme zweier Würfel mit der Faltungsformel
Prüfungsaufgabe (für sich allein lösbar). X, Y seien unabhängige faire Würfel, \(\Mem{S}=\mX+\mY\). (a) Schreibe die Faltungsformel für \(\PP(\Mem{S}=s)\) hin und berechne \(\PP(\Mem{S}=4)\) und \(\PP(\Mem{S}=7)\). (b) Berechne \(\EE[\Mem{S}]\) und \(\Var(\Mem{S})\) ohne die Verteilung von S. (c) Zwei unabhängige Normalverteilungen \(\Nor(2,1)\) und \(\Nor(3,4)\): welche Verteilung hat die Summe?
Lösung von null, Schritt für Schritt
1
(a) diskrete Faltung: alle Aufteilungen durchlaufen. \[\begin{aligned} \PP(\Mem{S}=s) &= \sum_{\Idx{k}}\PP(\mX=\Idx{k})\,\PP(\mY=s-\Idx{k}) && \text{Unabhängigkeit: Produkt, dann summieren} \\ \PP(\Mem{S}=4) &= \underbrace{\tfrac16\tfrac16}_{k=1}+\underbrace{\tfrac16\tfrac16}_{k=2}+\underbrace{\tfrac16\tfrac16}_{k=3}=\Res{\tfrac{3}{36}} && Y=3,2,1 \\ \PP(\Mem{S}=7) &= 6\cdot\tfrac{1}{36}=\Res{\tfrac16} && \text{jedes k von 1 bis 6 passt} \end{aligned}\]
2
(b) Abkürzung über Rechenregeln. \(\EE[\Mem{S}]=3.5+3.5=\Res{7}\); unabhängig → \(\Var(\Mem{S})=2\cdot\tfrac{35}{12}=\Res{\tfrac{35}{6}}\approx5.833\).
3
(c) Normal + Normal. Summe unabhängiger Normalverteilungen ist normal: \(\Nor(2+3,\ 1+4)=\Res{\Nor(5,5)}\).
✔ P(S = 4) = 3/36, P(S = 7) = 1/6; E[S] = 7, Var(S) = 35/6; N(2,1) + N(3,4) = N(5,5).
📘 Grundlage🔬 Anatomie: Faltung
\[ \Mem{S}=\mX+\mY:\qquad \ff_S(s)=\int_{-\infty}^{\infty}\ff_{X,Y}(x,\ s-x)\dd x\ \overset{\text{unabh.}}{=}\ \int_{-\infty}^{\infty}\ff_X(x)\,\ff_Y(s-x)\dd x \]
\(\text{Idee}\)für jede Summe s alle Aufteilungen \(x+(s-x)\) durchlaufen und die W'keiten aufsummieren (integrieren)
\(\text{Faltung}\)bei Unabhängigkeit ist \(\ff_S\) die Faltung (Konvolution) der beiden Randdichten
\(\text{Abkürzung}\)für \(\EE[S]\) oder \(\Var(S)\) braucht man die Faltung nicht: \(\EE[S]=\EE[X]+\EE[Y]\), \(\Var(S)=\Var(X)+\Var(Y)+2\Cov\)
📖 Vorlesen: „Die Dichte der Summe an der Stelle s ist das Integral über f X von x mal f Y von s minus x.“
📘 Grundlage⭐ Wichtig: Die Summe zweier unabhängiger Normalverteilungen ist wieder normalverteilt; man „verlässt“ die Normalfamilie nicht (Parameter nach den Rechenregeln).
📘 Grundlage
🎓 Prüfungs-Trainer. \(\mX\sim\Uni(0,2)\), \(\mY\sim\Uni(0,2)\) unabhängig. \(\EE[\mX+\mY]\), \(\Var(\mX+\mY)\) und die Form von \(\ff_S\)?
🗝️ ERKENNENSumme → E und Var direkt; Form = Faltung zweier gleich breiter Rechtecke.
⚙️ LÖSEN\(\EE[S]=\Res{2}\); \(\Var(S)=\tfrac4{12}+\tfrac4{12}=\Res{\tfrac23}\). Gleiche Breite ⟹ Dreieck auf [0, 4].
🗣️ SAGEN„E[S]=2, Var(S)=2/3, und f_S ist ein Dreieck auf [0,4].“
📘 Grundlage🧱 Bauplan: Uni(3,5) + Uni(6,10)

Zwei unabhängige Arbeitsprozesse: \(\mX\sim\Uni(3,5)\), \(\mY\sim\Uni(6,10)\). Gesamtzeit S = X + Y?

\[\begin{aligned} \EE[\Mem{S}] &= \tfrac{3+5}{2}+\tfrac{6+10}{2}=4+8=\Res{12} && \text{ohne Faltung} \\ \Var(\Mem{S}) &= \tfrac{(5-3)^2}{12}+\tfrac{(10-6)^2}{12}=\tfrac{4}{12}+\tfrac{16}{12}=\tfrac{20}{12}\approx\Res{1.667} && \text{unabhängig: addieren} \\ \ff_S &\ \text{ist trapezförmig auf }[9,\ 15] && \text{Faltung zweier Rechtecke} \end{aligned}\]

Die Faltung zweier „Kästen“ gibt ein Trapez (ein Dreieck nur bei gleicher Breite).

📘 Grundlage👁️ Woran erkennbar? Faltung Uni + Uni
