Parameterschätzungen

Ab jetzt beginnt die schließende Statistik: Aus wenigen Daten schließt man auf das Modell. Erst die Verteilungsfamilie wählen (QQ-Plot), dann die Parameter schätzen (Momentenmethode, Maximum-Likelihood), dann die Genauigkeit angeben (Erwartungstreue, Standardfehler, Vertrauensintervall).

rot · Ergebnis: berechneter Schätzwert, Intervallgrenzen
orange · Schätzer (Hut): \(\Chg{\hat\theta},\ \Chg{\hat\mu},\ \Chg{\hat p},\ \Chg{\hat\lambda}\): aus Daten gewonnen
lila · Methode/Funktion: Likelihood \(\Rule{L(\theta)}\), \(\Rule{\ell(\theta)}\), Momente, SE
blau · wahrer Parameter: \(\Par{\theta},\Par{\mu},\Par{\sigma},\Par{p},\Par{\lambda}\): unbekannt!
grün · Index/Ordnung: \(\Idx{i}\), Moment \(\Idx{k}\), \(\alpha_{\Idx{k}}\)
cyan · Bedingung: „gegeben θ“ \(p(x\given\theta)\), \(\overset{!}{=}\), Vertrauensniveau
pink · Daten: Beobachtungen \(\Mem{x_i}\), Zufallsvariablen \(\Mem{X_i}\)
📘 Grundlage🔗 Roter Faden: Daten → Verteilungsfamilie wählen (QQ-Plot) → Parameter schätzen (Moment/ML) → Genauigkeit angeben (Standardfehler, Vertrauensintervall). Der Hut trennt konsequent Wahrheit (blau, unbekannt) von Schätzung (orange, aus Daten).

6.0Master-Anatomie

der wahre Parameter des Modells: fest, aber unbekannt Realisierungen der i.i.d. Zufallsvariablen \(X_i\) der Schätzer: eine Funktion der Daten, selbst zufällig (andere Daten → anderes \(\hat\theta\)) Standardfehler = Standardabweichung des Schätzers „Das unbekannte Theta erzeugt die Daten; aus den Daten berechnen wir Theta-Dach plus/minus zwei Standardfehler.“
  1. ERKENNEN: Daten gegeben. Gefragt: passt die Verteilungsfamilie (QQ-Plot)? · welcher Parameterwert (Schätzung)? · wie genau (SE/VI)?
  2. WÄHLEN: Familie → Normalplot · Schätzen → Momentenmethode (Momente gleichsetzen) oder ML (Likelihood maximieren) · Genauigkeit → SE = σ/√n, VI = Schätzung ± 2·SE.
  3. RECHNEN: Moment: \(\mu_k(\theta)=m_k\) auflösen · ML: \(\ell(\theta)\) ableiten und = 0 setzen · dann SE und Intervall.
  4. ARTIKULIEREN: „Der [ML-/Momenten-]Schätzer ist θ̂ = […]; sein Standardfehler ist […]; das 95-%-VI ist θ̂ ± 2·SE = […].“
  1. Woher kommen die Daten? Realisierungen von i.i.d. Zufallsvariablen.
  2. Welche drei Fragen stellt die schließende Statistik? Schätzung · Test · Vertrauensintervall.
  3. Welche Verteilungsfamilie passt? QQ-/Normalplot.
  4. Wie schätzt man Parameter? Momentenmethode und Maximum-Likelihood.
  5. Sind die Schätzer gut? Erwartungstreu (darum n − 1!), ✚ konsistent.
  6. Wie genau? Standardfehler σ/√n und Vertrauensintervall.

6.1Einführung in die schließende Statistik

Von 200 zufällig befragten Personen nutzen 36 ein bestimmtes Produkt. (a) Formuliere das Modell. (b) Schätze den Anteil p. (c) Ordne die Fragen den drei Aufgaben der schließenden Statistik zu: „Ist p = 0.25 mit den Daten verträglich?“, „Welcher Bereich für p ist plausibel?“, „Welcher Wert für p ist am plausibelsten?“. (d) ✚ Schätze den Standardfehler von \(\hat p\). \(\Mem{X}\) = Anzahl Nutzer unter 200, \(X\sim\Bin(200,\Par{p})\) mit unbekanntem \(\Par{p}\); beobachtet \(\Mem{x}=36\). \(\Chg{\hat p}=\frac{x}{n}=\frac{36}{200}=\Res{0.18}\). „verträglich mit 0.25?“ → Test (Kap. 7) · „plausibler Bereich“ → Vertrauensintervall · „plausibelster Wert“ → Punktschätzung. \(\Var(\hat p)=\frac{p(1-p)}{n}\); mit \(\hat p\) eingesetzt: \(\operatorname{SE}\approx\sqrt{\frac{0.18\cdot0.82}{200}}\approx\Res{0.0272}\). Grobes 95-%-Intervall: \(0.18\pm2\cdot0.027=[0.126;\ 0.234]\); 0.25 liegt außerhalb. X ~ Bin(200, p); p̂ = 0.18; Test / VI / Punktschätzung; SE ≈ 0.027.

Bisher: Modell bekannt → Wahrscheinlichkeiten berechnen. Jetzt umgekehrt: aus wenigen Daten auf den zugrunde liegenden datengenerierenden Prozess schließen (induktive Logik).

 eine konkrete Beobachtung: ein realisierter Wert der Zufallsvariable \(X_i\) plausibelster Wert → Parameterschätzung · ist ein Sollwert verträglich? → Test (Kap. 7) · Bereich plausibler Werte → Vertrauensintervall (Kap. 7) der Hut: Schätzer für p. Vor der Realisierung ist \(\hat p=X/n\) eine Zufallsvariable, danach die Zahl \(x/n\) „Die beobachteten Daten x eins bis x n sind Realisierungen von i.i.d. Zufallsvariablen X eins bis X n.“ Man fragt: In welchem Bereich liegt der Parameter p plausibel? Welche der drei Fragestellungen ist das?Ein Bereich plausibler Werte → nicht Punktschätzung, nicht Test.Vertrauensintervall (Kap. 7).„Nach einem Bereich plausibler Werte fragt das Vertrauensintervall.“

n = 20 Bauteile, x = 5 defekt. Modell \(X\sim\Bin(20,p)\).

\[\Chg{\hat p}=\frac{x}{n}=\frac{5}{20}=\Res{0.25}\]

Der plausibelste Wert ist \(\hat p=0.25\). Bei nur 20 Beobachtungen ist das nicht exakt der wahre Wert, aber hoffentlich nahe dran. Wie nahe, sagt der Standardfehler (6.3.4).

6.2Wahl der Verteilungsfamilie: der QQ-Plot

Daten: 3.1, 4.8, 2.2, 5.9, 4.0. (a) Berechne die Punkte des Normalplots mit \(\alpha_k=\frac{k-0.5}{n}\). (b) Lies aus einer Geraden durch die Punkte grob μ und σ ab. (c) Wie sähe der Plot bei rechtsschiefen Daten aus? \(x_{(1)},\dots,x_{(5)}\) = 2.2, 3.1, 4.0, 4.8, 5.9. \(\alpha_k=0.1,0.3,0.5,0.7,0.9\) → \(z_{\alpha_k}=\Phi^{-1}(\alpha_k)=-1.282,\ -0.524,\ 0,\ 0.524,\ 1.282\). Punkte: \((-1.282;2.2)\), \((-0.524;3.1)\), \((0;4.0)\), \((0.524;4.8)\), \((1.282;5.9)\). Bei \(\Nor(\mu,\sigma^2)\) gilt \(q_\alpha=\mu+\sigma z_\alpha\): Achsenabschnitt ≈ μ, Steigung ≈ σ. Kleinste-Quadrate-Gerade: \(4.0+1.47\,z\) → \(\hat\mu\approx\Res{4.0}\), \(\hat\sigma\approx\Res{1.47}\) (zum Vergleich \(\bar x=4.0\), \(s=1.44\)). Rechtsschief: die Punkte krümmen sich nach oben (konvex), weil die großen Werte weiter auseinanderliegen als bei einer Glocke. Die fünf Punkte liegen fast auf einer Geraden mit Achsenabschnitt ≈ 4.0 und Steigung ≈ 1.47: Normalverteilung plausibel.

Bevor man Parameter schätzt, muss man die Familie wählen (z. B. „ist das normalverteilt?“). Das prüft man grafisch am besten mit einem QQ-Plot.

 empirische Quantile \(x_{(k)}\) (sortierte Daten) gegen theoretische Quantile \(F^{-1}(\alpha_k)\) des Modells stimmt das Modell, entsprechen sich die Quantile: die Punkte liegen ungefähr auf einer Geraden QQ-Plot gegen \(\Nor(0,1)\). Für \(\Nor(\mu,\sigma^2)\) gilt \(q_\alpha=\mu+\sigma z_\alpha\) → Gerade mit Achsenabschnitt μ und Steigung σ. Man muss die Parameter nicht kennen! „Man trägt die geordneten Daten gegen die Quantile der Modellverteilung auf; liegen die Punkte auf einer Geraden, passt die Familie.“
📘 Grundlage💡 Interpretation: Ein „invertiertes S“ (Enden wandern nach oben bzw. unten weg) bedeutet eine langschwänzige Verteilung: die extremen Werte sind größer, als eine Normalverteilung erwarten ließe.
Im Normalplot liegen die Punkte in der Mitte auf einer Geraden, biegen aber an beiden Enden weg (invertiertes S). Was bedeutet das?Beide Enden wandern weg → Schwänze dicker als bei der Normalverteilung.Die Daten stammen aus einer langschwänzigen Verteilung.„Ein invertiertes S bedeutet eine langschwänzige Verteilung, keine Normalverteilung.“
Erkennbar an: Normal → Gerade. Rechtsschief → nach oben gekrümmt. Langschwänzig → invertiertes S. Uniform → S-Form (Enden zu kurz).

6.3.1Momentenmethode

Wartezeiten seien \(\Uni(0,\Par{\theta})\) mit unbekanntem θ. Daten: 1.2, 3.9, 2.5, 4.4, 0.8. (a) Schätze θ mit der Momentenmethode. (b) Ist das Ergebnis mit den Daten verträglich? (c) Schätze μ und σ² einer Normalverteilung per Momenten, wenn \(m_1=10\), \(m_2=104\). Theoretisches Moment durch θ ausdrücken, dem empirischen gleichsetzen, auflösen. \[\begin{aligned} \mu_1(\theta) &= \EE[X]=\frac{\theta}{2} && \text{Mitte des Intervalls} \\ m_1 &= \bar x=\frac{1.2+3.9+2.5+4.4+0.8}{5}=2.56 && \text{empirisches Moment} \\ \frac{\theta}{2} &\overset{!}{=} 2.56\ \Rightarrow\ \Chg{\hat\theta_{\text{MM}}}=\Res{5.12} && \text{gleichsetzen und auflösen} \end{aligned}\] Alle Daten ≤ 4.4 < 5.12 ✓. (Aber: bei anderen Daten kann der Momentenschätzer kleiner als das Maximum ausfallen, dann ist er unmöglich. Die ML-Methode vermeidet das, siehe 6.3.2.) \(\mu_1=\mu\), \(\mu_2=\sigma^2+\mu^2\): \(\hat\mu=m_1=\Res{10}\), \(\hat\sigma^2=m_2-m_1^2=104-100=\Res{4}\). θ̂_MM = 2·x̄ = 5.12; Normal: μ̂ = 10, σ̂² = 4. Parameter so wählen, dass die theoretischen Momente (durch θ ausgedrückt) mit den empirischen übereinstimmen \(\mu_1=\EE[X]=\mu\), empirisch \(m_1=\bar x\): das arithmetische Mittel für r Parameter r Gleichungen \(\mu_1(\theta)=m_1,\dots,\mu_r(\theta)=m_r\) aufstellen und auflösen „Das k-te theoretische Moment E von X hoch k wird gleich dem k-ten empirischen Moment gesetzt“: einfach, aber nicht immer optimal. \(m_1=10\), \(m_2=104\). Schätze μ und σ² einer Normalverteilung per Momentenmethode.\(\mu_1=\mu\), \(\mu_2=\sigma^2+\mu^2\) gleichsetzen.\(\hat\mu=\Res{10}\); \(\hat\sigma^2=104-100=\Res{4}\).„μ̂ = m₁ = 10 und σ̂² = m₂ − m₁² = 4.“

\(\mu_1=\mu\), \(\mu_2=\EE[X^2]=\sigma^2+\mu^2\). Stichprobe: \(m_1=3.3\), \(m_2=11.9\).

\[\begin{aligned} 3.3 &= \mu,\qquad 11.9=\sigma^2+\mu^2 && \text{Gleichungssystem} \\ \Chg{\hat\mu} &= \Res{3.3},\qquad \Chg{\hat\sigma^2}=11.9-3.3^2=11.9-10.89=\Res{1.01} && \text{aufgelöst} \end{aligned}\]

Als Zufallsvariablen: \(\hat\mu=\bar X_n\) und \(\hat\sigma^2=\frac1n\sum X_i^2-\bar X_n^2\) (Momenten-Version mit Nenner n, vgl. 6.3.3).

6.3.2Maximum-Likelihood-Methode

n unabhängige Bauteile, jedes defekt mit W'keit p (Bernoulli). Beobachtet: x defekte. (a) Stelle Likelihood und log-Likelihood auf. (b) Leite den ML-Schätzer her. (c) Werte für n = 20, x = 5 aus und prüfe, dass es ein Maximum ist. Eine bestimmte Folge mit x Defekten hat W'keit \(p^x(1-p)^{n-x}\) (Unabhängigkeit): \[\Rule{L(p)}=p^{x}(1-p)^{n-x},\qquad \Rule{\ell(p)}=x\log p+(n-x)\log(1-p)\] (Der Faktor \(\binom nx\) hängt nicht von p ab und ändert die Lage des Maximums nicht.) \[\begin{aligned} \ell'(p) &= \frac{x}{p}-\frac{n-x}{1-p}\ \overset{!}{=}\ 0 && \text{Ableitung} \\ x(1-p) &= (n-x)\,p && \text{über Kreuz multipliziert} \\ \Chg{\hat p} &= \frac{x}{n} && \text{aufgelöst: relative Häufigkeit} \end{aligned}\] \(\hat p=\tfrac{5}{20}=\Res{0.25}\). \(\ell''(p)=-\frac{x}{p^2}-\frac{n-x}{(1-p)^2}<0\) → Maximum ✓. L(p) = pˣ(1−p)ⁿ⁻ˣ, p̂ = x/n = 0.25 (hier gleich dem Momentenschätzer). Likelihood ist keine W'keit für θ: \(L(\theta)\) integriert über θ nicht zu 1. Sie misst, wie gut θ die festen Daten erklärt. die Likelihood: die W'keit (bzw. Dichte), genau die beobachteten Daten zu sehen, als Funktion von θ. Wegen Unabhängigkeit ein Produkt das θ wählen, unter dem die beobachteten Daten am plausibelsten sind → L(θ) maximieren der Logarithmus macht das Produkt zur Summe: gleiches Maximum (log monoton), leichter abzuleiten „Die Likelihood ist das Produkt der W'keiten der einzelnen Beobachtungen; wir maximieren ihren Logarithmus.“ Poisson-Daten 2, 3, 1, 4, 0. Bestimme den ML-Schätzer \(\hat\lambda\).Für Poisson ist der ML-Schätzer das Stichprobenmittel.\(\hat\lambda=\bar x=\tfrac{10}{5}=\Res{2}\).„Der ML-Schätzer ist das Mittel: λ̂ = 10/5 = 2.“ \[\begin{aligned} \ell(\lambda) &= \sum_{i=1}^{n}\big(x_i\log\lambda-\lambda-\log(x_i!)\big)=\Big(\sum x_i\Big)\log\lambda-n\lambda-\text{const} && \text{log-Likelihood} \\ \frac{\partial\ell}{\partial\lambda} &= \frac1\lambda\sum_{i=1}^{n}x_i-n\ \overset{!}{=}\ 0 && \text{ableiten, null setzen} \\ \Chg{\hat\lambda} &= \frac1n\sum_{i=1}^{n}x_i=\bar X_n && \text{aufgelöst} \end{aligned}\]

Der ML-Schätzer für λ ist das Stichprobenmittel, hier gleich dem Momentenschätzer (nicht immer der Fall).
Erkennbar an: links die Daten (Balken) und die Poisson-W'keiten bei deinem λ; rechts die log-Likelihood \(\ell(\lambda)\). Ihr Maximum liegt genau beim Stichprobenmittel.

n = 5 Lebensdauern (Wochen): t = (1.2, 3.4, 10.6, 5.8, 0.9), Modell \(t_i\sim\Expo(\lambda)\).

\[\begin{aligned} \ell(\lambda) &= n\log\lambda-\lambda\sum t_i,\qquad \frac{\partial\ell}{\partial\lambda}=\frac{n}{\lambda}-\sum t_i\overset{!}{=}0 && \text{log-Likelihood und Ableitung} \\ \Chg{\hat\lambda} &= \frac{1}{\bar t},\qquad \bar t=\frac{21.9}{5}=4.38 && \text{Schätzer = 1 / Mittel} \\ \Chg{\hat\lambda} &= \frac{1}{4.38}\approx\Res{0.228} && \text{eingesetzt} \end{aligned}\]

Bei \(\Uni(0,\theta)\) ist \(L(\theta)=\theta^{-n}\) für \(\theta\ge\max x_i\), sonst 0. Die Funktion fällt in θ, also liegt das Maximum am Rand: \(\hat\theta_{\text{ML}}=\max x_i=4.4\) (für die Daten aus 6.3.1), während \(\hat\theta_{\text{MM}}=2\bar x=5.12\). Ableiten und null setzen funktioniert hier nicht (Maximum am Rand). Klausur-Merksatz: vor dem Ableiten den Definitionsbereich prüfen.

Code: das Maximum der log-Likelihood suchen

Eingabe: Poisson-Daten. Der Tracer berechnet \(\ell(\lambda)\) für λ = 0.5, 1, …, 4 und merkt sich den größten Wert; dann der Vergleich mit \(\bar x\).

6.3.3Allgemeine Schätzer für Erwartungswert und Varianz

(a) Zeige mit \(\EE\big[\sum(X_i-\bar X)^2\big]=(n-1)\sigma^2\), dass \(S_n^2\) (Nenner n − 1) erwartungstreu ist und der Momentenschätzer \(\hat\sigma^2_{\text{MM}}\) (Nenner n) nicht. (b) Wie groß ist der Bias bei n = 5, σ² = 1? (c) Daten 2, 4, 6: berechne beide Schätzwerte. \(\EE[\hat\theta]=\theta\): im Mittel über viele Stichproben kein systematischer Fehler. \[\begin{aligned} \EE[S_n^2] &= \frac{1}{n-1}\EE\Big[\sum(X_i-\bar X)^2\Big]=\frac{(n-1)\sigma^2}{n-1}=\sigma^2 && \text{erwartungstreu} \\ \EE[\hat\sigma^2_{\text{MM}}] &= \frac1n(n-1)\sigma^2=\frac{n-1}{n}\sigma^2<\sigma^2 && \text{unterschätzt systematisch} \end{aligned}\] Grund: die Abweichungen werden vom geschätzten \(\bar X\) statt vom wahren μ gemessen, und \(\bar X\) liegt immer „zu nah“ an den Daten. Bias \(=\frac{n-1}{n}\sigma^2-\sigma^2=-\frac{\sigma^2}{n}=\Res{-0.2}\) (20 % zu klein). \(\bar x=4\), \(\sum(x_i-\bar x)^2=4+0+4=8\): \(s^2=\tfrac82=\Res{4}\), \(\hat\sigma^2_{\text{MM}}=\tfrac83\approx\Res{2.667}\). S² ist erwartungstreu, der n-Schätzer hat Bias −σ²/n; Daten: 4 bzw. 2.667. das Mittel schätzt den Erwartungswert: \(\EE[\hat\mu]=\mu\), \(\Var(\hat\mu)=\sigma^2/n\) die empirische Varianz mit Nenner n − 1: \(\EE[\hat\sigma^2]=\sigma^2\) im Mittel treffen die Schätzer genau ihre Zielgröße, unabhängig von der Verteilung. Genau dafür steht das n − 1 „Mü-Dach ist X quer; Sigma-Quadrat-Dach ist die Summe der quadrierten Abweichungen durch n minus eins.“ Warum steht bei \(S_n^2\) der Nenner n − 1 statt n?Frage nach Erwartungstreue.Nur mit n − 1 gilt \(\EE[\hat\sigma^2]=\sigma^2\); mit n würde man um den Faktor (n−1)/n unterschätzen.„Der Nenner n−1 macht den Schätzer erwartungstreu: im Mittel trifft er genau σ².“
Erkennbar an: 4000 Stichproben aus \(\Nor(0,1)\) (wahre Varianz 1). Mit Nenner n liegt der Mittelwert der Schätzungen (rote Linie) unter 1, mit n − 1 genau auf 1.

Ein Schätzer heißt konsistent, wenn er für \(n\to\infty\) gegen den wahren Wert strebt: \(\PP(|\hat\theta_n-\theta|\ge\varepsilon)\to0\). \(\bar X_n\) ist nach dem GGZ (Kap. 5) konsistent für μ. Auch der verzerrte n-Schätzer ist konsistent, weil sein Bias \(-\sigma^2/n\to0\). Erwartungstreu und konsistent sind also verschiedene Eigenschaften.

6.3.4Genauigkeit von Schätzern: Standardfehler und Vertrauensintervall

16 Messungen ergeben \(\bar x=21.3\). Die Messstreuung ist bekannt: σ = 4. (a) Standardfehler? (b) 95-%-Vertrauensintervall. (c) 99-%-Intervall. (d) Wie viele Messungen braucht man, damit das 95-%-Intervall höchstens ±0.5 breit ist? \(\operatorname{SE}=\frac{\sigma}{\sqrt n}=\frac{4}{4}=\Res{1}\). \[\begin{aligned} I &= \bar x\pm z_{0.975}\,\frac{\sigma}{\sqrt n} && \text{Rezept} \\ &= 21.3\pm1.96\cdot1=\Res{[19.34;\ 23.26]} && \text{eingesetzt} \end{aligned}\] \(21.3\pm2.576=\Res{[18.72;\ 23.88]}\): höhere Sicherheit → breiteres Intervall. \[\begin{aligned} 1.96\cdot\frac{4}{\sqrt n} &\le 0.5 && \text{halbe Breite} \\ \sqrt n &\ge \frac{1.96\cdot4}{0.5}=15.68\ \Rightarrow\ n\ge245.9 && \text{quadriert} \\ n &= \Res{246} && \text{aufrunden} \end{aligned}\] SE = 1; 95 %: [19.34; 23.26]; 99 %: [18.72; 23.88]; n = 246. „95 % Vertrauen“ heißt nicht „μ liegt mit W'keit 0.95 in diesem Intervall“ (μ ist fest), sondern: das Verfahren fängt μ in 95 % aller Stichproben ein (siehe Wand unten). „the data could have been different“: bei einer neuen Stichprobe käme ein anderer Wert; der Schätzer ist normalverteilt um μ Standardfehler = Standardabweichung des Schätzers = \(\sigma/\sqrt n\). Je größer n, desto genauer (√n-Gesetz) \(\hat\mu\pm z_{0.975}\sigma/\sqrt n\) mit \(z_{0.975}=1.96\approx2\): fängt den wahren Wert mit W'keit 0.95 ein „Schätzung plus/minus zwei Standardfehler.“
📘 Grundlage🎯 Merkregel: „Schätzung ± 2 Standardfehler“. Ein schmales Intervall = genaue Schätzung. Erst die Modellannahmen (hier Normal, σ bekannt) machen ein solches Intervall möglich. Ist σ unbekannt, braucht man die t-Verteilung (Kap. 7).
n = 64, bekannte σ = 16, Mittel 100. Standardfehler und 95-%-VI?SE = σ/√n; VI = Schätzung ± 2·SE.\(\operatorname{SE}=\tfrac{16}{8}=\Res{2}\); \(100\pm4=\Res{[96;104]}\).„SE = 16/8 = 2, also 95-%-VI = 100 ± 4 = [96, 104].“

n = 100, σ = 10, \(\hat\mu=50\).

\[\begin{aligned} \operatorname{SE} &= \frac{10}{\sqrt{100}}=\Res{1} && \text{Standardfehler} \\ I &= 50\pm2\cdot1=\Res{[48;\ 52]} && \text{exakt }50\pm1.96=[48.04;\ 51.96] \end{aligned}\]
Erkennbar an: 100 Stichproben aus \(\Nor(0,1)\), jede mit ihrem Intervall \(\hat\mu\pm z\cdot1/\sqrt n\). Rote verfehlen μ = 0. Der Anteil der Treffer liegt nahe am Niveau; ein größeres n macht die Intervalle schmaler, ändert aber die Trefferquote nicht.

📐 Schema: Schätz-Aufgabe in 3 Schritten

  1. Modell und Familie: welche Verteilung (ggf. Normalplot)? Welcher Parameter unbekannt?
  2. Schätzen: Momentenmethode oder Maximum-Likelihood → \(\hat\theta\).
  3. Genauigkeit: SE (z. B. σ/√n), dann \(\hat\theta\pm2\,\text{SE}\).
Bin: 5 von 20 defekt.\(\hat p=0.25\) (Schätzer = relative Häufigkeit). Exp-ML aus 5 Lebensdauern (t̄ = 4.38).\(\hat\lambda=1/\bar t\approx0.228\). n = 100, σ = 10, \(\hat\mu=50\).SE = 1, 95-%-VI = 50 ± 2 = [48, 52] (voller Dreischritt).

🌉 Die große Brücke: von Daten zum Modell und seiner Genauigkeit

  • Ich kann mit der Momenten- und der Maximum-Likelihood-Methode Parameter schätzen.
  • Ich kann mit einem QQ-/Normalplot die Verteilungsfamilie grafisch prüfen.
  • Ich kenne Erwartungstreue (✚ und Konsistenz), Standardfehler und Vertrauensintervall.
  • Ich kann das benötigte n für eine Wunschgenauigkeit berechnen.
